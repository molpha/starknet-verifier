# Molpha Starknet Verifier

Verify the same threshold-signed Molpha payload on Starknet, EVM, and Solana.

The Molpha Starknet Verifier is a Cairo implementation of the Molpha verification library. It allows Starknet applications to verify threshold-signed external data produced by the Molpha network without bridges, relayers, or Starknet-specific signing rounds.

A single payload generated by Molpha can be verified natively on every supported VM.

## How it works

```
External API
      │
      ▼
Molpha verifier nodes
(fetch independently)
      │
      ▼
Threshold signature
      │
      ▼
Common payload
      ├────────► EVM
      ├────────► Solana
      └────────► Starknet
```

The Starknet verifier performs exactly the same verification as the EVM and Solana implementations.

No bridge.
No message passing.
No chain-specific oracle network.

## Verification flow

1. Independent Molpha nodes fetch the requested API.
2. A threshold of nodes signs the canonical payload.
3. The payload is submitted to Starknet.
4. The verifier reconstructs the aggregate public key.
5. The Schnorr signature is verified.
6. The application trusts the payload if verification succeeds.

## Historical registry versions

Node set updates never invalidate previously signed payloads.

Each registry modification creates a new immutable registry version while preserving previous public keys.

Every payload references the registry version it was signed against.

This guarantees that historical signatures remain verifiable forever.
